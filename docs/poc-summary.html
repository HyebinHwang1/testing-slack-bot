Slack 봇 PoC — 섹션 분류 + 담당자 자동 태그

사업부 문의를 봇이 자동으로 분류해 답변하고, 담당자를 태그해 라우팅까지 안내하는 PoC.

기반: 개발팀 지식 봇 "철수" (Slack ↔ Claude ↔ Supabase ↔ React)

왜 만들었나

기존 (As-Is)

  • 사업부가 Slack 채널에 문의/개발 요청을 올림
  • QA가 수동으로 담당자를 찾아 일일이 라우팅
  • 반복 질문도 매번 사람이 대응 → 병목

개선 (To-Be)

  • 봇이 채널 메시지를 자동 감지
  • 질문의 섹션을 분류 → 지식베이스로 즉시 답변
  • 해당 섹션 담당자를 자동 태그해 후속 문의 연결

채널 메시지 감지

사업부가 채널에 글을 올리면 message.channels 이벤트 수신. (봇/스레드/짧은 글은 필터)

섹션 분류

어드민에 등록된 섹션 목록(이름+설명)을 Claude에 주고 질문이 어느 섹션인지 분류 (없으면 미분류).

지식베이스 답변

저장된 Q&A(qa_items) 전체를 컨텍스트로 Claude가 답변 생성.

담당자 태그 + 답글

분류된 섹션에 담당자가 있으면 답글 끝에 @담당자를 붙여 스레드로 응답.

철수앱 · 방금

※ 멘션(@철수 …)으로 물어도, 멘션 없이 그냥 올려도 동일하게 분류·태그된다.

이번 PoC에서 추가한 것
구성내용
DBsections 테이블 신규 — 섹션명·설명·담당자(Slack ID)·담당자명
APIapi/sections.ts — 섹션 CRUD (GET/POST/PUT/DELETE)
Slackevents.ts — message 자동 감지 + composeReply(섹션 분류 → 답변 → 담당자 태그). 기존 멘션 저장/질문 플로우 유지
Web#/admin/sections 섹션 관리 페이지 (목록·추가·수정·삭제)

설계 원칙 — 섹션은 담당자 매칭용 분류일 뿐, 답변은 항상 전체 지식베이스에서 생성. 기존 qa_items 스키마·저장 플로우는 건드리지 않음.

기술 스택
Slack Events API @slack/web-api Claude (claude-haiku-4-5) @anthropic-ai/sdk Vercel Serverless Supabase PostgreSQL postgres.js React 19 Vite TailwindCSS TypeScript pnpm
로컬 데모 실행
# 1) 환경변수 (.env.local) 준비 — DATABASE_URL / ANTHROPIC_API_KEY / SLACK_BOT_TOKEN / SLACK_SIGNING_SECRET
# 2) 섹션 테이블 (최초 1회, Supabase SQL Editor)
psql ... < scripts/sections-schema.sql

# 3) API + 웹 기동
pnpm dev:api   # vercel dev → localhost:5001 (.env.local을 source)
pnpm dev:web   # vite → localhost:5173

# 4) Slack 로컬 연결
ngrok http 5001
# Slack 앱 → Event Subscriptions Request URL = https://<ngrok>/api/slack/events
# 봇 이벤트: app_mention + message.channels / 스코프: channels:history / 봇 채널 초대

어드민: http://localhost:5173/#/admin/sections 에서 섹션·담당자 등록 후, 채널에 관련 질문을 올려 동작 확인.
