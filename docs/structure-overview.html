데이터 모델 (qa_items)
🗄️ qa_items
id VARCHAR Primary key
question TEXT Q&A 질문 내용
answer TEXT 답변 (Markdown 포함 가능)
author_slack_id VARCHAR 질문 작성자 Slack ID
curator_slack_id VARCHAR 답변 작성자 Slack ID
view_count INT 조회수 (default: 0)
is_deleted BOOLEAN 소프트 딜리트 (default: false)
created_at / updated_at TIMESTAMP 생성/수정 시각
